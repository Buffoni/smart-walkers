# Smart Walkers

This repo holds the code for the Smart Walkers project.

## Folder structure

- `swalkers/`: Main package containing the implementation of the Smart Walkers algorithms.
- `bridge_formula_test.ipynb`: Jupyter notebook for testing the connection between the transition matrices and the q-table.
- `get_all_the_figures_for_paper.ipynb`: Jupyter notebook to generate all the figures for the paper (contains the main experiments).
- `smartness_test.ipynb`: Jupyter notebook for testing some details regarding the smart walker case.
- `theory_tests.ipynb`: Jupyter notebook for testing the main general theoretical results of the paper, for walkers moving in discrete space.
